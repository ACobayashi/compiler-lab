\section{引言}

本实验旨在了解源程序从预处理、编译、汇编到链接生成可执行文件的完整过程，并熟悉 LLVM IR、RISC-V 汇编以及 MLIR 中端处理中的基本表示和转换方法。

在小题1中，我们分别对 C 程序和 C++ 阶乘程序执行预处理、编译、汇编和链接，结合预处理文件、token、中间表示、汇编、目标文件和可执行文件，分析宏展开、控制流、符号和库函数调用在各阶段的表示，并比较编译参数带来的代码变化。

在小题2中，我们共同设计 SysY 程序和测试数据，编写 LLVM IR 与 RISC-V 汇编，并将程序与 SysY 运行时库链接，运行测试，分析数组访问、循环、分支、函数调用和输入输出的结果。

\section{实验安排}
在小题1中，成员A在 Ubuntu 22.04 Docker 容器中使用 Clang/LLVM 14.0.0、GCC 11.4.0 和 Graphviz 2.43.0 分析 C 程序，并生成 AArch64 汇编和 ELF 文件；成员B在 WSL2 Ubuntu 22.04 中使用 GCC 11.4.0 分析 C++ 阶乘程序，并使用 Clang 14 输出 token 序列，目标平台为 x86-64。在小题2中，成员A在 Ubuntu 22.04 Docker 容器中以 x86-64 Linux 为目标编写 LLVM IR；成员B使用课程提供的 RV64 交叉工具链和 QEMU 编写、链接并运行 RISC-V 程序。

在进阶部分中，我们在 WSL2 Ubuntu 22.04 中使用 MLIR 14、\texttt{mlir-opt-14}、\texttt{mlir-translate-14} 和 Clang 14 处理矩阵乘法程序。
