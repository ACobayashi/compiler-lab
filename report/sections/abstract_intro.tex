\section{引言}
编译命令可以生成预处理文件、词法 token、中间表示、汇编和目标文件，但平时编译时这些文件往往不会保留。小题1从两个 C/C++ 程序出发，分别保存这些产物，并与源程序对照。通过这些文件，可以看到宏展开、类型检查、控制流、符号和库调用在不同阶段留下的结果。

小题2使用同一份 SysY 程序。成员A编写 LLVM IR，成员B编写 RISC-V 汇编；两份代码都链接 SysY 运行时库。使用相同的测试数据执行两种程序，检查数组、循环、分支、函数调用和输入输出是否正确。

\section{实验环境与总体方法}
成员A的小题1实验在 WSL2 Ubuntu 22.04 环境中完成，主要使用 GCC 11.4.0，并在词法分析阶段使用 Clang 14 输出 token 序列，目标平台为 x86-64。成员B的小题1实验在 Ubuntu 22.04 Docker 容器中完成，主要使用 Clang/LLVM 14.0.0、GCC 11.4.0、Graphviz 2.43.0；流程实验另观察 AArch64 目标汇编与 ELF 文件。成员A的 LLVM IR 实验以 x86-64 Linux 为运行目标，在 Ubuntu 22.04 Docker 容器中完成。RISC-V 部分使用课程提供的交叉工具链与 QEMU，目标为 RV64，并链接课程提供的 SysY RISC-V 运行时库。

实验内容分为两部分。第一部分使用 C/C++ 程序，保存预处理文件、token、GCC tree、CFG、RTL、汇编、目标文件和可执行文件，并比较不同编译参数带来的变化。第二部分以共享 SysY 程序为准，分别完成 LLVM IR 和 RISC-V 版本，再通过汇编、链接和多组输入检查两种实现的输出。
