\subsection{成员B：GCC 编译流程实验}

在 WSL2 Ubuntu 22.04 中，使用 g++ 11.4.0 对 C++ 阶乘程序执行 GCC 的预处理、编译、汇编和链接，目标平台为 x86-64。首先生成各阶段结果，再比较不同编译参数下的代码。源程序包含自定义头文件、普通宏、带参宏、条件编译、全局变量、全局常量、函数、条件分支和循环。

\subsubsection{实验准备}

在自定义头文件 \texttt{test.h} 中，定义了输入上限 \texttt{N}、带参宏 \texttt{mul(a,b)} 和条件编译宏 \texttt{DEBUG}，如图~\ref{fig:q1-testh} 所示。

\labfigure{figures/memberB/q1/image1.png}{自定义头文件 test.h}{fig:q1-testh}

在 \texttt{main.cpp} 中，定义了全局变量 \texttt{times}、全局常量 \texttt{start}、阶乘函数 \texttt{factorial(int n)} 和主函数，如图~\ref{fig:q1-maincpp} 所示。

\labfigure{figures/memberB/q1/image2.png}{主程序 main.cpp}{fig:q1-maincpp}

\subsubsection{编译器内部阶段}

这一部分中，我们依次查看词法分析、语法分析、语义分析、中间代码生成、代码优化和代码生成的结果。我们使用 GCC 输出 tree、CFG 和 RTL，并使用 Clang 输出 token 序列。

\paragraph{词法分析}

使用 Clang 输出 \texttt{main.cpp} 的 token 序列。为了减少标准头文件产生的大量输出，只保留来源于 \texttt{main.cpp} 的 token：

\begin{lstlisting}[language=bash]
clang++ -Xclang -dump-tokens -fsyntax-only main.cpp 2>&1 \
  | grep "main.cpp:" | head -n 60
\end{lstlisting}

在 token 序列中，包含 \texttt{using}、\texttt{int}、\texttt{const}、\texttt{for} 等关键字，\texttt{times}、\texttt{factorial} 等标识符，以及数值常量和运算符。宏展开生成的 token 保留了 \texttt{test.h} 的位置信息，如图~\ref{fig:q1-token} 所示。

\labfigure{figures/memberB/q1/lexical_1.png}{Clang 输出的 main.cpp 词法 token 序列}{fig:q1-token}

生成的 tree 文件如图~\ref{fig:q1-treegen} 所示。

\paragraph{代码优化}

使用同一个预处理文件分别生成 \texttt{-O0} 和 \texttt{-O2} 两个版本的汇编：

\begin{lstlisting}[language=bash]
g++ -O0 -S -masm=att output/main.ii -o output/main_O0.s
g++ -O2 -S -masm=att output/main.ii -o output/main_O2.s
\end{lstlisting}

如图~\ref{fig:q1-o0o2} 所示，\texttt{-O0} 版本约为 3.6 KB、193 行，\texttt{-O2} 版本约为 4.2 KB、222 行。

\labfigure{figures/memberB/q1/image18.png}{-O0 与 -O2 汇编文件比较}{fig:q1-o0o2}

再比较两个版本中的 \texttt{factorial} 函数。\texttt{-O2} 版本使用寄存器保存循环变量和中间结果，循环体主要由 \texttt{imulq}、\texttt{addq}、\texttt{cmpq} 和 \texttt{jne} 等指令组成，\texttt{times++} 变为直接对内存加一；与 \texttt{-O0} 相比，栈内存读写有所减少，如图~\ref{fig:q1-o2fact} 所示。

\labfigure{figures/memberB/q1/image19.png}{-O2 下 factorial 函数的汇编结果}{fig:q1-o2fact}


\paragraph{代码生成}

在代码生成阶段，使用 \texttt{-S} 让 GCC 在生成汇编后停止，得到 x86-64 AT\&T 语法的 \texttt{main\_O0.s}，如图~\ref{fig:q1-codegen} 所示。

\subsubsection{本小题小结}

在本小题中，预处理结果展示了 \texttt{N}、\texttt{mul(result,i)} 和 \texttt{DEBUG} 的展开情况；tree、CFG 和 RTL 分别展示了程序的树结构、基本块关系和更接近机器层的表示。目标文件符号表中，函数、零初始化全局变量和外部符号分别带有 \texttt{T}、\texttt{B} 和 \texttt{U} 标记。

比较不同编译参数后，\texttt{-O2} 版本的 \texttt{factorial} 减少了栈内存读写；加入 \texttt{-g} 后，文件中增加了调试相关段；加入 \texttt{-fno-omit-frame-pointer} 后，汇编保留了 \texttt{\%rbp} 栈帧。静态链接版本约为 2.3 MB，动态链接版本约为 17 KB；优化报告记录了阶乘循环的向量化结果。
