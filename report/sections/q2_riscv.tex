\subsection{成员B：RISC-V 汇编编程}

成员B负责 RISC-V 汇编的编写，源码归档在 \path{riscv/memberB/main.s}。根据共享的 SysY 程序，编写数组输入、偶数求和和正数个数统计的汇编代码，并与 \path{shared/sysy/lib/} 中的运行时库链接。使用 \texttt{qemu-riscv64} 运行测试数据，再检查目标文件和最终可执行文件中的函数符号。以下命令从 \path{riscv/memberB/} 执行。

\subsubsection{寄存器使用}

我们将数组首地址和长度分别放入 \texttt{a0} 和 \texttt{a1}，将函数返回值写入 \texttt{a0}。在 \texttt{main} 中，我们使用 \texttt{s0} 保存 $n$，使用 \texttt{s1} 保存循环变量，使用 \texttt{s2} 保存数组基址，并在栈中保存 \texttt{ra} 和 \texttt{s0--s2}；栈帧大小为 80 B，保持 16 B 对齐。

\begin{table}[H]
\centering

\begin{tabularx}{0.96\linewidth}{>{\ttfamily}p{3.1cm} >{\ttfamily}p{4.2cm} X}
\toprule
\normalfont SysY 结构 & \normalfont RISC-V 指令/寄存器 & \normalfont 作用 \\
\midrule
函数参数 a、n & a0、a1 & 传递数组首地址和数组长度 \\
return & a0 & 保存函数返回值 \\
a[i] & slli + add + lw/sw & 计算数组元素地址并进行读写 \\
while & 条件分支 + 标签 + 回跳 & 控制循环执行 \\

在访问 \texttt{a[i]} 时，先用 \texttt{slli} 将下标左移 2 位得到 $i\times4$，再用 \texttt{add} 与数组基址相加，最后通过 \texttt{lw} 或 \texttt{sw} 读写数组元素。在 \texttt{sum\_even} 中，\texttt{remw} 计算元素除以 2 的余数，\texttt{bnez} 跳过奇数；在 \texttt{count\_pos} 中，\texttt{blez} 跳过非正数。

\subsubsection{RISC-V 汇编代码}

完整 RISC-V 汇编代码如下：

\begin{lstlisting}[language=RiscVAsm,caption={RISC-V 汇编程序 main.s},label={lst:riscv-main}]
.option nopic
.attribute stack_align,16
.text

.globl sum_even
.type sum_even,@function
sum_even:
#初始化
    li t0,0
    li t1,0
.Lse_loop:
    bge t0,a1,.Lse_end
    slli t2,t0,2
    add t3,a0,t2
    lw t4,0(t3)
#判断偶数
    li t5,2
    remw t6,t4,t5
    bnez t6,.Lse_next
    addw t1,t1,t4
.Lse_next:
    addi t0,t0,1
    j .Lse_loop
.Lse_end:
    mv a0,t1
    ret
.size sum_even,.-sum_even

.globl count_pos
.type count_pos,@function
count_pos:
#初始化
    li t0,0
    li t1,0
.Lcp_loop:
    bge t0,a1,.Lcp_end
    slli t2,t0,2
    add t3,a0,t2
    lw t4,0(t3)
#统计正数
    blez t4,.Lcp_next
    addiw t1,t1,1
.Lcp_next:
    addi t0,t0,1
    j .Lcp_loop
.Lcp_end:
    mv a0,t1
    ret
.size count_pos,.-count_pos

.globl main
.type main,@function
main:
#开辟栈空间
    addi sp,sp,-80
    sd ra,72(sp)
    sd s0,64(sp)
    sd s1,56(sp)
    sd s2,48(sp)

    mv s2,sp

#输入n
    call getint
    mv s0,a0
    li s1,0

#输入数组
.Linput:
    bge s1,s0,.Linput_end
    call getint
    slli t0,s1,2
    add t0,s2,t0
    sw a0,0(t0)
    addi s1,s1,1
    j .Linput

.Linput_end:
#求偶数和
    mv a0,s2
    mv a1,s0
    call sum_even
    call putint
    li a0,10
    call putch

#统计正数
    mv a0,s2
    mv a1,s0
    call count_pos
    call putint
    li a0,10
    call putch

    li a0,0
    ld s2,48(sp)
    ld s1,56(sp)
    ld s0,64(sp)
    ld ra,72(sp)
    addi sp,sp,80
    ret
.size main,.-main
\end{lstlisting}

\subsubsection{生成可执行文件}

在生成可执行文件时，先使用 RISC-V 交叉编译器将 \texttt{main.s} 汇编为目标文件 \texttt{main.o}：

\begin{lstlisting}[language=bash]
cd riscv/memberB
riscv64-unknown-elf-gcc main.s -c -o main.o -w
file main.o
\end{lstlisting}

使用 \texttt{file} 检查 \texttt{main.o}，输出包含 \texttt{ELF 64-bit}、\texttt{relocatable} 和 \texttt{UCB RISC-V}，表明该文件为 64 位 RISC-V 可重定位目标文件。

在输入输出部分，调用 SysY 运行时库中的 \texttt{getint}、\texttt{putint} 和 \texttt{putch}。使用下面的命令将 \texttt{main.o} 与 \texttt{libsysy\_riscv.a} 静态链接：

\begin{lstlisting}[language=bash]
riscv64-unknown-elf-gcc main.o -o main \
  -L../../shared/sysy/lib -lsysy_riscv \
  -static -mcmodel=medany \
  -Wl,--no-relax,-Ttext=0x90000000
\end{lstlisting}

第一次链接时，SiFive GCC-Metal 10.2.0 工具链报告 \texttt{zmmul} ISA 属性不兼容。使用 \texttt{type -a} 确认工具链路径后，将课程工具链放到 \texttt{PATH} 前端并重新生成 \texttt{main.o}，链接完成。

\subsubsection{本部分小结}

在 RISC-V 汇编中，使用 \texttt{slli}、\texttt{add} 和 \texttt{lw} 访问数组元素，使用 \texttt{remw} 和 \texttt{bnez} 判断偶数，使用 \texttt{blez} 判断正数。\texttt{main} 使用 80 B 栈帧保存 \texttt{ra} 和 \texttt{s0--s2}，函数调用时通过 \texttt{a0} 和 \texttt{a1} 传递数组地址和长度。将 \texttt{main.s} 汇编为 \texttt{main.o} 后，与 \texttt{libsysy\_riscv.a} 静态链接生成 RISC-V 可执行文件；测试通过，符号表中包含程序函数和 SysY 运行时库的输入输出函数。
